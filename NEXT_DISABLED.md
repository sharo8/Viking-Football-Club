# Ancienne version Next.js — désactivée

Le site officiel est maintenant uniquement dans `website/`.

Pour lancer le site :

```bash
npm run dev
```

Le dossier `src/` (Next.js) n’est plus utilisé par `npm run dev`.
Ne l’ouvre plus via `next dev` / `localhost:3000` de Next — tu verrais l’ancienne version (gros logo au milieu, etc.).
