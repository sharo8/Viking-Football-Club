# Viking FC — Official Club Website

Professional football club website for **VIKING FC** (Next.js).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Design

- Light theme by default (white / burgundy / bronze)
- Dark mode toggle in the header
- Cinzel · Work Sans · JetBrains Mono
- Scroll reveals via IntersectionObserver (React-safe)
